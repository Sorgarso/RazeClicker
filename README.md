## Features

- **Precise CPS control.** Set 100 CPS and get 100 CPS. Choose clicks per second, minute, hour or day.
- **Mouse clicker.** Left or right button, Toggle or Hold mode.
- **Multi-location clicking.** Click through your own list of screen coordinates.
- **Keyboard auto clicker.** Repeat any key at a set rate.
- **Macro recorder.** Record mouse and keyboard actions and play them back with exact timings, once or in a loop.
- **Custom hotkeys.** Bind start/stop to the key you want.
- **Always on top.**
- **Built-in updates.** The app notifies you when a new version is out and can update itself.
- **No ads, no telemetry.**

## Quick start

1. Download `RazeClicker.exe` from the [latest release](https://github.com/Sorgarso/RazeClicker/releases/latest).
2. Run it and accept the license agreement.
3. Choose the mouse button and the activation hotkey.
4. Pick a mode: **Toggle** (press to start/stop) or **Hold** (clicks while the key is held).
5. Set the click count and period.
6. Optionally add click locations.
7. Press the hotkey to start or stop.

### Macro recorder

1. Enable the recorder and press **Rec**.
2. Perform your actions. Press **ESC** to stop recording.
3. Press **Play once** or **Play Inf**. Press **F1** to stop playback.

## Getting Started

### Installation

1. Visit the [latest release](https://github.com/Sorgarso/RazeClicker/releases/latest).
2. Download `RazeClicker.exe`.
3. Run the executable.
4. Accept the license agreement.

### Clicker

1. Open the **Clicker** tab.
2. Select Mouse mode or Keyboard mode.
3. Configure the clicking speed and time unit.
4. Select the mouse button if using Mouse mode.
5. Choose your activation hotkey.
6. Select an activation mode:
   - **Hold** — clicking continues while the hotkey is held.
   - **Toggle** — press the hotkey to start or stop clicking.
7. Press the configured hotkey to activate the clicker.

### Pick Location

1. Open the **Pick Location** tab.
2. Enable Pick Location.
3. Press **Pick From Screen** to select a screen position.
4. Add and manage your saved coordinates.
5. The clicker can use your configured locations when location-based clicking is enabled.

### Macro Recorder

1. Open the **Recorder** tab.
2. Press the configured Recording Hotkey (F5 by default).
3. Perform your mouse and keyboard actions.
4. Press the Recording Hotkey again to stop recording.
5. Press the Playback Hotkey (F6 by default) to play the recording.
6. Choose between **Once** and **Infinite** playback modes.
7. Press the Playback Hotkey again or stop playback as configured.

## Settings

RazeClicker provides several customization options:

- **Language** — choose your preferred interface language.
- **Start on Windows** — automatically launch RazeClicker when Windows starts.
- **Hotkeys** — configure global shortcuts for the application's main actions.

to check for updates and download new releases.

No personal information or usage statistics are collected.

## Building from Source

RazeClicker is an open-source project written in Rust.

### Requirements

- [Rust](https://www.rust-lang.org/tools/install)
- [Git](https://git-scm.com/)

### Build

Clone the repository:

```bash
git clone https://github.com/Sorgarso/RazeClicker.git
cd RazeClicker
```

Build the optimized release version:

```bash
cargo build --release
```

The compiled executable will be located in:

```text
target/release/
```
